pmequitherapie.fr

Ce dépôt contient le code source du site pmequitherapie.fr, développé avec Eleventy (11ty) et géré via Sveltia CMS (compatible Decap/Netlify CMS).

Structure du projet

  • /admin/ : Interface CMS (Sveltia/Decap) et configuration
  • /images/, /assets/ : Images et ressources statiques
  • /*.md : Pages du site au format Markdown (éditables via le CMS)
  • /_includes/ : Templates Nunjucks
  • /.eleventy.js : Configuration Eleventy

Environnements

  • Développement : repo Viguro79/pmequitherapie (branche feat/workinprogress)
  • Staging : build déployé sur Viguro79/pmequitherapie_staging (gh-pages)
  • Production : build déployé sur Viguro79/pmequitherapie_website (gh-pages), relié au domaine personnalisé

Édition du contenu

Le contenu (pages, tarifs, etc.) est éditable via /admin grâce à Sveltia CMS.
L’authentification se fait via GitHub OAuth.

Déploiement

Les workflows GitHub Actions automatisent :

  • Le build Eleventy selon l’environnement (ELEVENTY_ENV)
  • La copie de la bonne config CMS
  • Le déploiement sur le repo cible (staging ou production)
